# Open-source foundations

FEHM reuses selected algorithms, rule definitions and skill content with recorded attribution. Bundling an adaptation does not install the complete upstream project or its services.

## Engine and analysis

THIRD_PARTY_NOTICES.md records selected adaptations from AgentMemory, Codebase Memory, ECC, Graft and Skylos, plus asset notices. Consult that file for exact revisions and licenses rather than inferring capabilities from an upstream project name.

## Skill catalog

The catalog includes workflows from several sources. Skill metadata, skills/source-map.json and skills/licenses/ record provenance. Install only the skills relevant to your work. Imported instructions remain subordinate to user/project instructions and grant no permissions.

## Superpowers

Five existing workflows were refreshed with supporting resources and FEHM-specific evidence guidance. The selected snapshot reports version 7.0.1 without a verified commit SHA. Per-file hashes and adaptations are recorded in skills/superpowers-provenance.json. Read [Superpowers workflows](superpowers.md).
