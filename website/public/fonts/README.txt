Locally hosted typefaces

Manrope variable sans-serif and Newsreader variable italic serif are distributed
under the SIL Open Font License. Their license notices are included alongside
the fonts. Latin and punctuation subsets are served as compressed WOFF assets.
Other characters use the CSS system-font fallback.

Source files:
https://github.com/google/fonts/tree/main/ofl/manrope
https://github.com/google/fonts/tree/main/ofl/newsreader

The generated assets preserve the original license notices. No font service is
contacted by the website. FontTools was used for subsetting and WOFF conversion;
it is not a website build or runtime dependency.
